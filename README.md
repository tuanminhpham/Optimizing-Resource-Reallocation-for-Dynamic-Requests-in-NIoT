# Optimizing Resource Reallocation for Dynamic Requests in NIoT

This repository contains the source code and executables for evaluating the proposed solutions presented in the following paper:

**Pham, Tuan-Minh and Nguyen, Thi-Minh**,  
*“Optimizing Resource Allocation for Dynamic IoT Requests Using Network Function Virtualization,”*  
*IEEE Transactions on Network Science and Engineering*, 2025, pp. 1–13.  
DOI: [10.1109/TNSE.2025.3565736](https://doi.org/10.1109/TNSE.2025.3565736)

## Repository Structure

The project is organized into two main parts:

1. **Source Code**

   The `src` folder includes all source code, organized into three subfolders based on the algorithms used for model evaluation:

   - **1.1. Optimal Solutions and Approximation Algorithms** – Implemented in Java  
   - **1.2. DRL-based Algorithm** – Implemented in Python using deep reinforcement learning  
   - **1.3. Dataset Generator** – A Python script to generate datasets required for model evaluation

2. **Test Cases and Executables**

   This section includes test cases and executable files (Java and Python).  
   For detailed instructions on how to run the code, please refer to the `README.txt` file.
